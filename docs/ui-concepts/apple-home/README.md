# 首页视觉概念：实底与通透

本目录是用于选择视觉方向的独立 HTML/CSS 示例，不是正式 APP 的功能改版。
用户已选择通透风格、苹果蓝、手机优先、浅深色；首页只将四项目标中的「喝水」替换为运动，其他内容和顺序保留。下方喝水汇总及饮食页的饮水记录不受影响。

## 设计契约

- 原始参照：`src/views/HomeView.vue`、`src/components/Home*.vue`、`src/components/TopBar.vue`、`src/config/nav.ts`。
- 保留内容顺序：问候日期 → 四项目标 → 今日时间带 → 提示与昨日最重要事项 → 接下来 → 本周学习 → 未来七天 → 六个模块汇总。
- 保留五个底部入口：今天、日程、学习、生活、复盘；保留设置和记一笔入口。
- 主要工作：浏览当天生活状态；主要入口：记一笔、目标指标与各模块按钮。
- 四版使用同一份固定演示数据，不读取或更改应用数据库；日期固定为用户本地日期 2026-11-07。
- 实底版本保留原稿；通透版本第三项改为「运动 / 待训练 / 今日计划：上肢力量」，与健身页待训练状态一致。
- 主要视口 390×844，额外检查 320×844、430×844、1440×900；宽屏仅展示居中的手机概念，不代表桌面端设计已完成。
- 实底：中性灰页面、白色或炭灰表面、分组细线、稳定底栏。
- 通透：淡蓝光感背景、半透明表面、轻描边与浮动底栏；不使用外部图片、字体、库或联网资源。
- 数字使用对齐数字；文字、次级文字、强调色与实色时间块文字检查最低 4.5:1 对比度；半透明表面的数值检查依据底色合成，另做截图观察。
- 可见按钮最低 44px 高；键盘焦点可见；支持减少动态效果；浏览器不支持模糊时使用实色回退。

## 查看

当前完整交付入口：**`gallery.html`**。顶部可以切换浅色/深色；每页提供首屏、完整长图与静态 HTML 示例入口。首页八个区块的单独大图也在同一画廊中。

覆盖现有全部 12 个路由页面：首页、日程、读书、书籍详情、科目、计时器、错题本、饮食、健身、娱乐、复盘、设置。页面元数据及本地源文件参照见 `pages.js`，测试与 `src/router/index.ts` 的实际路由清单比对。

另含六个表单：新增计划、学习结算、添加书籍、添加科目、记错题、记录晚餐。学习结算示例只提供保存/丢弃，不添加关闭按钮。表单仅展示样式，不代表实际保存逻辑或焦点约束已完成。

截图目录：`screenshots/glass-pages/`。每页有浅/深色首屏与完整长图；`daily/study/life/forms-*-overview.png` 是四组总览，`home-<区块>-<主题>.png` 是首页单独区块。

直接打开 `comparison.html` 查看四版首屏对照。

打开 `index.html?material=solid&theme=light` 可滚动查看完整示例；参数 material 可选 solid/glass，theme 可选 light/dark。
从文件系统打开时，可在浏览器地址栏追加参数；截图均位于 `screenshots/`，`*-full.png` 为完整长图。

所有示例按钮打开说明弹窗；关闭按钮或 Escape 关闭，并返回按钮焦点。示例不冒充正式导航、保存或计时功能。

## 验证

在仓库根目录运行：

```powershell
node docs/ui-concepts/apple-home/verify.mjs
node docs/ui-concepts/apple-home/verify-pages.mjs
```

脚本使用项目已安装的 Playwright 与系统 Chrome，无需安装依赖；检查四版内容一致性、模块数量、导航、四种宽度无横向溢出、点击区域、核心文本颜色对比度、键盘与弹窗反馈、减少动态效果、浏览器错误与离线约束，并重建截图与对照页。

`verify.mjs` 额外断言：四版除第三项目标之外的首页文字一致；通透版显示运动，实底版保持喝水；下方喝水汇总仍存在。
`verify-pages.mjs` 断言：覆盖全部产品路由、浅深色内容一致、对应底部导航高亮、320/390/430px 无横向溢出、输入有标签、按钮高度、示例反馈、键盘焦点、减少动态效果、离线运行、画廊主题切换及图链更新。另保存 1440px 居中手机视图，未设计桌面版布局。

已人工查看四版首屏对照、实底浅色完整长图、通透深色完整长图和 320px 窄屏截图。未见指标文字溢出、标题遮挡或模块缺失。底栏覆盖首屏下沿的部分滚动内容，完整内容可继续滚动，页尾留有底栏安全空间。

全模块检查：人工查看八张浅深色汇总图，另查看窄屏训练表、错题表单及代表性完整长图。浮动底栏有意覆盖滚动内容，完整长图在内容之后呈现底栏。书架封面是本地排版的概念封面，非原版封面。

内容状态范围：本页为固定且完整的演示数据，不进行异步加载、权限请求或真实读写。因此加载、空数据、错误与部分数据恢复属于后续正式组件接入的验收范围，本次不声称完成；已验证的反馈仅是预览弹窗的打开、说明、关闭与焦点返回。

未修改正式 APP 页面、数据逻辑或既有 `docs/UI_GUIDE.md`；选定方向后再制定正式迁移规则。
