# UI 规范：通透 · 苹果蓝

依据：用户确认的 docs/ui-concepts/apple-home/gallery.html 通透方案。正式实现保留本地数据、原有入口和首页内容顺序，顶部摘要中的饮水改为运动，底部饮水记录保留。

## 视觉规则

- 系统无衬线字体，数字使用 tabular-nums；不用手写体、纸纹、斜贴标签或硬投影。
- 浅色冰蓝背景与半透明白色表面；深色深蓝背景与半透明蓝灰表面。模糊只用于独立面板和导航，不层层堆叠。
- 正文、辅助文字、苹果蓝和语义色在各主题背景上的对比度至少 4.5:1。正文按钮使用 accent-fill / on-accent 配对。
- 输入与按钮圆角 14px，卡片 24px，浮动导航与底部表单 30px，胶囊 999px；边线 1px。
- 删除、失败使用 danger；成功使用 success；提醒使用 warning。颜色集中定义于 src/assets/main.css，组件不得写死颜色。
- 主内容由 src/assets/glass.css 统一处理材质和响应式；局部组件负责结构和业务状态。
- 图标使用本地内联 SVG，圆头细线；不引入外部字体、CDN 或 UI 依赖。

## 布局与交互

首页依次为问候、四项摘要、真实时间带、提醒、接下来、本周学习、未来七天、模块摘要。手机四项摘要两列，桌面四列；七天保持七列并在下方展示完整任务名称。所有摘要从现有 store 读取，禁止展示示例数据。

移动端保留设置与记一笔入口，底栏五项导航悬浮于安全区上方，正文留出遮挡空间。普通表单在手机上贴底，桌面居中；长表单正文可滚动，保留关闭和保存入口。主要触摸控件至少 44px。

日程页使用开放工具栏、七天日期条和分隔线清单，避免外框层层嵌套；今天使用 accent-soft，选中日期使用细蓝描边。手机日期条下补充完整任务名称。日期跳转按钮使用胶囊圆角；手机或粗指针设备隐藏所有电脑快捷键提示。

普通按钮按下轻微缩小并降低透明度，90ms；完成反馈 180ms；所有动效不超过 300ms，支持减少动态效果。键盘焦点使用 2px 苹果蓝描边，禁止隐藏。加载、空态、错误、保存状态使用原有业务反馈，不用装饰性动画伪装进度。

## 错题分类补充

错题本汇总全部日期，不显示日期控件或全局日期提示。使用同一套通透圆角标签选择科目和知识点；支持无错题时先创建分类。分类科目可暂不设置学习周目标，已有错题缺少知识点时仍可在「全部知识点」查看。分类字段随 JSON 备份恢复，题目的知识点也进入文本导出。

录题表单以圆角选项选择科目，并可原地新增。题目、订正各自整合文字、拍照、上传和缩略图，支持纯照片保存。图片处理期间禁用保存，错误提示保留重试入口。错误原因多选按钮、照片操作及删除均至少44px，掌握状态使用整行可点的开关，深浅色共享语义令牌。

首页七天使用紧凑日期条和单日预览：默认今天，选择其它日期只更新本区；最多显示三条，未完成优先，同状态按时间排序。时间、标题、完成状态同时呈现，长标题最多两行。更多安排通过「查看当天全部」进入对应日期的列表，空日期不再批量列行。窄屏日期条可横向滑动以保留44px触摸目标。


复盘页使用开放数字排版和日记式输入，去掉汇总格子、层层外框和评分按钮边框。评分、心情、精力触摸目标至少44px，以苹果蓝区分选中。输入暂停400ms自动保存；短暂失败保留当前输入与本地恢复草稿并允许重试，切日期及离页前完成待保存队列。页首不提供日期切换；历史列表点击展开只读详情，编辑、补写和自选区间均在历史区操作。删除已写比例和精力提示；趋势与历史间距36px，空态采用“生成曲线”。
