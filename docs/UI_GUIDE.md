# UI 规范：Evan的专属APP

依据：已确认的首页和侧边栏效果图。本文件是界面实现的唯一依据，交给 DeepSeek 时和 `AGENTS.md` 一起读。
适用范围：所有页面。新页面先用这里的组件和变量，不自己发明样式。

---

## 1. 硬性规则

1. **所有颜色、间距、圆角必须用 CSS 变量**，组件里不写死颜色值。
2. **浅色、深色两套都要做**：变量在 `:root` 定义浅色，深色在 `[data-theme="dark"]` 里只重新定义变量；设置里选"跟随系统"时用 `prefers-color-scheme`。
3. **不联网**：不引入任何 CDN、Google Fonts、在线图标。字体和图标全部本地（见第 3 节）。
4. 图标统一用**线条图标**（描边 1.7px、圆角端点），内联 SVG，不用 emoji 当图标。心情选择的表情除外。
5. 数字列对齐的地方（时间、计时、时长、页码）一律加 `font-variant-numeric: tabular-nums`。
6. 键盘焦点必须可见（2px 主色描边，偏移 2px）。
7. 尊重 `prefers-reduced-motion`：开启时关闭脉冲等动画。
8. 页面不得出现横向滚动条。

## 3. 字体

| 角色 | 字体栈 | 用途 |
|---|---|---|
| 正文 | `"PingFang SC","Microsoft YaHei","Noto Sans SC",system-ui,sans-serif` | 所有中文和一般文字 |
| 数字 | `"Outfit","PingFang SC","Microsoft YaHei",system-ui,sans-serif` | 大数字、时间、计时、统计 |

---

## 4. 间距、圆角、边框

| 项 | 值 |
|---|---|
| 页面内容区内边距 | 24px |
| 卡片之间间距 | 14px |
| 卡片内边距 | 16px（问候大块 28px） |
| 卡片圆角 | 16px |
| 按钮、胶囊圆角 | 999px（完全圆角） |
| 列表行圆角 | 10px |
| 边框 | 1px `--line`；问候大块无边框 |
| 阴影 | 默认不用。只有弹窗和下拉用一层轻阴影 |

---

## 5. 整体布局与组件规范

- 侧栏：宽 236px，可折叠至 68px。
- 顶栏：无手动"保存"按钮，右侧常驻轻量状态提示（"已自动保存 ✓" / "保存中…"）。计时胶囊显示运行中或待结算状态。
- 普通弹窗：取消 + 保存，Esc 可关；**计时结算弹窗**：只有保存和丢弃，不能按 Esc 或点遮罩关闭。
