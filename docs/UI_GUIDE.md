# UI 规范：Evan的专属APP

依据：已确认的 v5 效果图（`D:\项目文件\UI设计\mockups\home-desktop-v5.png` / `home-phone-v5.png`，规则详解见同目录 `方向与规则-v5.md`）。本文件是界面实现的唯一依据，交给 DeepSeek 时和 `AGENTS.md` 一起读。
适用范围：所有页面。新页面先用这里的组件和变量，不自己发明样式。

风格基调：**灰绿纸 + 松绿场 + 朱砂信号 + 新粗野主义**（2px 墨线、硬投影、直角、等宽数字），外加两个「材质层」：荧光笔和手写。

---

## 1. 硬性规则

1. **所有颜色、间距、圆角必须用 CSS 变量**，组件里不写死颜色值（`styleTokens.spec.ts` 会扫描 `.vue` 里的 `#hex` / `rgb(` / `hsl(`）。
2. **浅色、深色两套都要做**：变量在 `:root` 定义浅色，深色在 `[data-theme="dark"]` 里只重新定义变量；设置里选"跟随系统"时用 `prefers-color-scheme`。
3. **不联网**：不引入任何 CDN、Google Fonts、在线图标。字体和图标全部本地（见第 3 节）。
4. 图标统一用**线条图标**（描边 1.7px、方头端点 `stroke-linecap: square`），内联 SVG，不用 emoji 当图标。心情选择的表情除外。
5. 数字一律 `font-variant-numeric: tabular-nums`；时间、日期、件数、时长优先用等宽数字（`.num` / `.mono` / `var(--font-mono)`）。
6. 键盘焦点必须可见（2px 主色描边，偏移 2px）。
7. 尊重 `prefers-reduced-motion`：开启时关闭脉冲等动画。
8. 页面不得出现横向滚动条。
9. **朱砂（`--danger`）只表示「逾期 / 没做」**，一屏最多两处；它是信号，不是装饰。

## 3. 字体

| 角色 | 字体栈 | 用途 |
|---|---|---|
| 正文 | `"PingFang SC","Microsoft YaHei","Noto Sans SC",system-ui,sans-serif` | 所有中文和一般文字（15px 起） |
| 数字 | `var(--font-mono)` = `ui-monospace,"Cascadia Mono",Consolas,monospace` | 时间、日期、件数、时长、刻度 |
| 手写 | `var(--font-hand)` = `"KaiTi","楷体","Kaiti SC","STKaiti",serif` | 只给左下角那句便签（见 §6.3） |

字号三档：**大标题 26–52px（700 字重）/ 正文与数字 15px / 元信息 12px**。

## 4. 形状、边框、投影

| 项 | 值 |
|---|---|
| 页面内容区内边距 | 20–26px |
| 卡片之间间距 | 16px |
| 卡片内边距 | 14–16px（首页松绿场 24–30px） |
| 圆角 | **一律 `--radius` = 2px**（全站直角；`--radius-card`/`--radius-pill` 同为 2px） |
| 边框 | 外框 **2px `--border-ink`**；内部细分隔 1px `--border` |
| 硬投影 | `offset-x offset-y 0 墨`，**无模糊**：卡片 4–5px、场 7px、按钮 2–3px |
| 第二层投影 | `--slab`（灰片）偏移翻倍：场 14px、面板 10px —— 像两叠纸 |
| 柔和阴影 / 毛玻璃 / 渐变 | **不用**（浮层也用硬投影） |
| 网格纸纹理 | 只铺内容区（`.content`），侧栏 / 顶栏是**实心纸**，不跟内容滚动 |
| 原生配色 | `:root` 写 `color-scheme: light`、`[data-theme='dark']` 写 `dark`，滚动条与表单控件跟着主题走 |

## 5. 整体布局与组件规范

- 侧栏：宽 212px，2px 墨线右边框，可折叠至 68px。顺序：今天 / 日程 → 学习分组（读书·科目·计时器）→ 生活分组（饮食·健身·娱乐）→ 底部单独一组（复盘·设置）→ 手写便签 → "数据只在本机"。
- 当前项 = **反相块**（墨底反白 + 3px 灰硬影），不是色条。
- 顶栏：高 54px，2px 墨线下边框；无手动保存按钮，右侧轻量状态（"已保存 21:33"，等宽数字）；最右是主按钮「＋ 记一笔」（墨底反白 + 朱砂硬影）。
- 底部导航（手机）：5 个 tab，当前项整块反相（墨底反白）。
- 普通弹窗：取消 + 保存，Esc 可关；**计时结算弹窗**：只有保存和丢弃，不能按 Esc 或点遮罩关闭。
- 面板标题用**贴上去的标签**（`.tag`：2px 框 + 3px 硬影 + 歪 -1.2°），压住面板上边框。

## 6. 三种「工艺细节」的使用规则

### 6.1 贴标签（`.tag`）
只给面板标题用；一屏不超过 3 个；文字不加 emoji、不超过 6 字。

### 6.2 荧光笔（`mark.hl`）
- 一屏**最多两处**：一处划「接下来第一件要动手的事」，一处划手写句里的关键词。
- 形状是手划痕（歪 1°、斜切 7°、四角半径不同），**不是色块**。
- 禁止：划数据（数字 / 日期 / 图表）、划标题、划超过 6 个字。

### 6.3 手写便签（`.hand-note`）
- 一句话 ≤ 10 字/行、最多两行，一句人话；不用感叹号、不喊口号、不用 emoji。
- 整块歪 -1.2°，下方配一行等宽日期戳（`10.24 · 写给今天`）。
- **一屏只出现一次**，位置固定左下角（桌面＝侧栏底部，手机＝「接下来」面板之后）；绝不压在数据上。

---

## 7. 首页 / 日程 的分工

- **首页放大概**：问候（日期·星期·时间）+ 一条粗时间带（约 5 件事）+ 接下来 3 条 + 本周学习 7 根柱 + 未来七天摘要。
- **日程放详细**：默认窗口「今天前一天 → 今天后五天，共 7 天」；7 列天 × 三泳道（学习 / 生活 / 其它）× 06:00–24:00，块里带标题与起止时间，可编辑；点某天展开成单日时间轴；空的一天写「还没有安排」。
- **时间带状态**：已完成 = 反白实块 + 1px 墨线；进行中 = 反白块 + 硬影 + 深色光标线穿过；逾期 = 朱砂实块 + 反白「没做」；未到 = 反白描边透明底；现在 = 2px 反白竖线 + 「现在 21:33」。
