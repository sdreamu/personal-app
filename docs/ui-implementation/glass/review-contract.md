# 复盘页设计约定

手机优先，延续通透材质、苹果蓝和克制文字层级。用户先浏览当天汇总，然后记录自评，最后查看历史与趋势。以用户提供的九条页面批注为设计依据。

- 汇总以开放数字排版呈现，移除格子和外框；自评采用无框评分和日记式输入，控件触达至少 44px。
- 历史采用分隔列表、胶囊区间、折叠自选日期；点击展开只读详情，编辑或补写在历史区进入，页首无日期切换。
- 输入暂停 400ms 自动保存，评分同样自动保存。切日期及离页前冲刷队列；失败保留输入和本地草稿并提供重试；旧写入不得覆盖新输入。
- 历史不显示已写比例；趋势与历史至少间隔 32px，空态使用“生成曲线”。
- 验证尺寸：320x720、390x844、699x668、1440x900。浅色、深色均需检查；长文本换行、键盘焦点和减少动态效果可用。

状态：加载显示进度且暂不允许编辑；空历史显示补写入口；保存失败提供重试并保留草稿；部分评分允许保存且趋势保留缺口；保存成功显示安静状态并更新历史；权限不适用，仅读写已有浏览器本地存储，无新增权限请求。
