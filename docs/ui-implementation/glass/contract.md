# 通透 UI 实施约定

以已确认的 `docs/ui-concepts/apple-home/gallery.html` 通透方案为参考，应用到真实 Vue 页面。保留首页区块顺序、业务数据和已有入口；仅将顶部四项摘要中的饮水替换成真实运动状态，饮水快捷记录保留。

手机以单手快速记录和查看今日进度为主。浅色采用冰蓝背景、半透明白色表面、苹果蓝；深色采用深蓝灰背景、半透明深色表面。层级依靠字号、留白、细分隔线和轻投影，去除旧的纸纹、硬投影、手写和斜贴标签。底部导航浮起，表单在手机上以底部面板呈现。

目标视口：320x812、390x844、430x932、1440x900。检查所有真实路由的浅深主题、长文本溢出、44px 主要触摸目标、键盘焦点、减少动态效果及保留的操作流程。

日程页复核新增 614x547 视口：工具栏先于七天概览；采用无外框的开放布局、淡蓝今日日期与细线选中态，手机七天日期横排，下方保留任务名称清单。日期跳转按钮改为胶囊圆角。手机宽度或粗指针设备隐藏日程、日期弹层与学习计时器的电脑快捷键提示，保留桌面键盘操作。

状态：加载保留结构与现有加载提示；空数据说明下一步；错误保留错误条及重试入口；部分记录只展示已有内容；完成保留保存/撤销反馈。应用本地优先，无新增授权请求；文件选择通过原生控件取消安全返回。

错题本改为跨日期的长期知识库：隐藏日期控件与日期提示，用可换行的科目、知识点圆角标签进行两级筛选，44px 最小触摸目标。无需已有错题或学习目标即可创建科目，知识点可单独添加；新增题目继承当前分类，旧题缺少新字段仍可见。保持标题、录入按钮、掌握状态、分类、题卡的清晰顺序，去掉页头外框。加载显示进度，读取失败可重试；分类保存失败保留输入，成功确认并可继续录题；空分类提供录题入口；字段随 JSON 备份恢复。

录题表单复核：科目用圆角选项选择，空分类可在表单内新增；题目和订正各自整合文字、拍照、相册与缩略图，不将照片拆到表单后方。支持只有照片的错题，处理图片时禁用保存，失败显示恢复提示。错误原因采用至少44px的圆角多选按钮及选中勾；掌握状态为整行可点、带文字状态的开关。沿用通透苹果蓝与深浅主题，在320x812、390x844、614x547和1440x900复核弹层顶部/底部、键盘焦点、长选项、图片错误及保存恢复。相机用浏览器capture输入，由设备决定可用方式；桌面模拟文件录入，不声称已完成手机相机实测。

首页七天概览复核：紧凑七天日期条显示日期与数量，默认今天，点日期只更新本区预览，不立即跳页或改变全局日期。下方最多三条选中日安排，显示时间、标题及完成状态；完整清单入口打开该日列表。空日只出现一句提示，不为每个空日列行。沿用当前昨天至后五天窗口，保持既有日期范围；日期条内部可横向滚动以保留44px触摸宽度。加载有提示，单日查询失败可重试且其它日期仍可读。目标320x812、390x844、614x547、1440x900，两主题检查长标题两行截断、键盘焦点与三条上限。
