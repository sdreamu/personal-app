# 安卓适配第一阶段（2026-11-07）

## 本次变化

- 顶栏移除日期与明暗切换，新增常驻设置齿轮。主题在设置内切换，日期控件移入相关页面内容区，历史日期与复盘草稿切换确认继续可用。
- 手机书架按想读、在读、读完切换单列列表；长标题换行，按钮可换行，页码、编辑和删除操作保留。手机普通模式不启用整卡拖拽，排序模式使用触摸手柄和上下移按钮；支持边缘滚动与取消手势，排序写入原有数据。
- 书卡展示区域避免长按选中文字，页码输入仍允许文本选择。点击页码标签只聚焦输入框。
- 今日精力改为 1–5 档圆形按钮及状态文字。曲线显示独立数据点，单日、间断记录也可见；缺失日期继续断线，心情与精力用不同线型、点大小区分。
- 页面使用动态视口高度并补充安全区、可收缩布局和长文本换行；弹窗高度受视口限制，正文可滚动；Android 配置 adjustResize。日程周导航适配窄屏换行。
- Android 版本 1.0.1 / versionCode 2，包名仍为 com.evan.personalapp，数据库结构未修改。
