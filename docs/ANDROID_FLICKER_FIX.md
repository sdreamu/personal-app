# 安卓闪动修复（1.0.2）

## 问题与修改

- 页面切换原先使用 out-in：旧页先淡出到透明，再挂载新页。帧采样复现了日程入口的空白帧。改为路由内容直接交接，按钮按下、进度条、完成反馈和弹窗动效保留。
- 日程七天网格与首页未来七天原先等待数据库查询结束才生成列，手机两列布局会突然撑开。首帧即生成七天布局，标题和完成数区域预留高度；查询并行完成后更新内容。刷新不再整块变暗，快速翻周时丢弃较旧查询的结果。
- 饮食页把 loading 纳入空状态判断，每次加减水都会短暂从空状态切成四餐列表再切回来。改为根据已载入的餐食数据判断空状态，刷新期间保留现有内容。
- 保存状态的文字长度不同，会推动顶栏设置按钮，实测旧版横移约 18px。为保存提示预留稳定宽度。
- 内部按钮按下时外层卡片也匹配 :active，鼠标按住已复现整卡与按钮同时位移。卡片遇到内部控件正在按下时保持原位；卡片采用自定义反馈，移除系统默认触摸高亮。
- 书籍详情更新页码、摘录时原先卸载整页正文；娱乐记录编辑保存时原先卸载已有列表。刷新期间保留现有节点，仅首次载入显示加载提示。浏览器 DOM 观察器已复现旧行为，并验证修复后不会替换原节点。
- Android versionCode 3 / versionName 1.0.2，沿用包名 com.evan.personalapp。未修改数据库结构。
