# 个人生活助手

一个**本地优先**的个人生活管理应用：把日程、学习、读书、健身、饮食、娱乐计时和复盘放在同一个页面里，
所有数据只存在你自己浏览器的 IndexedDB 里——没有后端、没有账号、不上传任何东西。

> 项目名 `evan-personal-app` 是仓库里沿用的包名；界面上显示的应用名统一取自 `src/config/app.ts` 的 `APP_NAME`。

## 功能一览

| 模块 | 能做什么 |
| --- | --- |
| 日程 | 按天排计划（时间块 / 待办），支持跨天顺延、按分类分组、勾选完成 |
| 学习 | 科目与错题本；学习计时支持正计时与倒计时，到点会提醒并可直接开始下一轮 |
| 读书 | 书架（想读 / 在读 / 读完）、阅读进度与页码更新、拖拽排序、每本书的阅读记录 |
| 健身 | 训练类型与动作库、今日训练按组记录（重量 / 次数）、每周训练计划、历史记录 |
| 饮食 | 按餐次记录吃了什么，喝水按杯数累计，自动对比每日目标 |
| 娱乐计时 | 娱乐时间计时 + 每日额度，可正计时或倒计时，超额会提示 |
| 复盘 | 每日 / 每周回顾，自动汇总当天与本周的数据（学习、饮食、训练、娱乐占比） |
| 备份 | 备份导出为 JSON 并支持导入还原；另有 Markdown 文本导出，方便交给 AI 分析（含图片 base64） |

首页是当天的仪表盘：问候语、日期、今天的下一步、七个趋势小卡，以及各模块的入口。

## 技术栈

- **Vue 3 + TypeScript + Vite**，单页应用，hash 路由
- **Pinia** 状态管理，一个模块一个 store
- **Dexie / IndexedDB** 持久化，本地优先、**无后端、无网络请求**，数据只在本机浏览器里
- **Vitest + @vue/test-utils**（单元 / 组件，jsdom + fake-indexeddb）、**Playwright**（端到端）
- 样式手写，无第三方 UI 库；浅色 / 深色通过 CSS 变量切换

## 如何运行

```bash
pnpm install      # 安装依赖
pnpm dev          # 开发服务器：http://127.0.0.1:5173
```

> 端口固定 5173 且 `strictPort: true`：浏览器按域名+端口隔离存储，换端口会看到"空数据库"。
> 想同时开第二个实例做调试，用 `pnpm run dev:5180`（读 `.env.dev5180`）。

常用脚本：

```bash
pnpm test          # 单元 / 组件测试（vitest run）
pnpm test:e2e      # 端到端测试（Playwright，需要本机安装 Chrome）
pnpm run typecheck # vue-tsc --noEmit
pnpm build         # 类型检查 + 生产构建
```

## 数据与隐私

- 所有数据都存在**当前浏览器的 IndexedDB** 里（数据库名固定），刷新、关标签页、重启浏览器都不丢；
  换浏览器 / 换端口 / 清站点数据会看不到旧数据。
- 删除是软删除（带回收窗口），后台 GC 只清理过期的软删除记录。
- 备份导出是**纯 JSON 文件**，图片以 base64 内嵌在里面；导入会覆盖当前数据（覆盖前自动导出一份备份）。
- 没有任何网络请求：应用不联网、不埋点、不依赖远程服务，代码里也没有账号体系。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `index.html` / `src/main.ts` | 入口；挂载前先开库、读设置、落主题，避免白屏或先亮后暗 |
| `src/config/` | 应用身份（`app.ts`：应用名 + 问候语）、导航结构、开发端口 |
| `src/router/` | 路由表（11 个页面入口） |
| `src/views/` | 页面组件（首页、日程、学习、生活、复盘、设置） |
| `src/components/` | 可复用组件（顶栏、首页卡片、计时胶囊、弹窗、表单等） |
| `src/stores/` | Pinia stores（date / plan / library / diet / workout / play / review / timer / settings …） |
| `src/db/` | Dexie 数据库、schema、CRUD、备份导入导出、迁移 |
| `src/utils/` | 日期（逻辑日期 / 一天起点）、图片、下载、拖拽排序等纯函数 |
| `src/assets/` | 手写全局样式（CSS 变量主题） |
| `e2e/` | Playwright 端到端用例 |
| `docs/` | 产品需求（PRD）、UI 规范、现状盘点与后续计划 |
